# Code of conduct

Be kind, be specific, assume good faith. We want people of every experience level to feel able to report a
bug, ask a question or send a fix.

* Criticise code and ideas, not people. Explain *why* when you disagree.
* No harassment, discrimination, personal attacks, or publishing other people's private information.
* Respect that this project protects people's data: pressure to "just skip the safety check" is not a
  reason to skip it.

Maintainers may remove comments, close issues or pull requests, and block people who break these rules.
