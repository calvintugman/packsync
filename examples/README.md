# Examples

| File | What it is |
|---|---|
| `settings.json` | A complete `settings.json` with the defaults (the app writes it for you; every key is optional). |
| `rules-extra.toml` | Extra "what to sync" rules for one instance. |
| `google-oauth.example.json` | The *shape* of the file Google lets you download for an OAuth client. **Placeholders only** — never commit the real file; `.gitignore` already excludes `google-oauth.json` and `client_secret*.json`. |
